# tglight

Легковесный клиент для Telegram, написанный на Rust. Сфокусирован на минимальном потреблении ресурсов, быстродействии и базовом функционале для обмена сообщениями.

---

## ⚡ Особенности

- **Rust-стек**: Высокая скорость работы и безопасность памяти при минимальном оверхеде.
- **Низкие требования**: Отсутствие тяжелых веб-движков (Electron/Chromium).
- **Кроссплатформенность**: Базовая поддержка сборки под Windows и Linux.
- **CI/CD Автоматизация**: Готовые бинарные сборки компилируются через GitHub Actions.

---

## 🛠 Стек технологий

- Язык: [Rust](https://www.rust-lang.org/)
- Сетевая логика: [Tokio](https://tokio.rs/) / Telegram API
- Сборка и релизы: GitHub Actions

---

## 📦 Установка и запуск

### Готовый бинарник (Windows)
1. Перейдите во вкладку [Releases](../../releases).
2. Скачайте свежий архив `tglight-windows-exe`.
3. Распакуйте и запустите `tglight.exe`.

### Сборка из исходников

Для ручной сборки потребуется установленный [Rust Toolchain](https://rustup.rs/):

```bash
# Клонирование репозитория
git clone [https://github.com/ayrat7/tglight.git](https://github.com/ayrat7/tglight.git)
cd tglight

# Сборка оптимизированного релиза
cargo build --release
